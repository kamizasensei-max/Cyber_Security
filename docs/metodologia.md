# Metodologia

## Etapa 1 - Descoberta de Serviços

Inicialmente foi realizado um reconhecimento da máquina alvo.

Ferramenta utilizada:

- Nmap

Objetivos:

- Identificar portas abertas
- Detectar serviços ativos
- Verificar versões conhecidas

## Etapa 2 - Análise de Autenticação FTP

Foram avaliados:

- Existência de autenticação por usuário e senha
- Configurações inseguras
- Possíveis credenciais padrão

## Etapa 3 - Avaliação do DVWA

Foram observados:

- Formulário de autenticação
- Mecanismos de validação
- Respostas a credenciais inválidas

## Etapa 4 - Compartilhamentos SMB

Foram avaliados:

- Compartilhamentos disponíveis
- Restrições de acesso
- Enumeração de informações públicas

## Coleta de Evidências

Para cada etapa foram registradas capturas de tela contendo:

- Configuração do ambiente
- Serviços identificados
- Resultados das análises
