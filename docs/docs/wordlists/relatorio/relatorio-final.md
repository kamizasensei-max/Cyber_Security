# Relatório Final

## Introdução

O presente trabalho teve como objetivo a construção de um ambiente de laboratório utilizando Kali Linux, Metasploitable 2 e DVWA.

O ambiente permitiu o estudo dos mecanismos de autenticação presentes em diferentes serviços de rede.

## Ambiente Utilizado

### Kali Linux

Sistema empregado para atividades de análise e avaliação de segurança.

### Metasploitable 2

Máquina vulnerável utilizada para treinamento.

### DVWA

Aplicação web vulnerável destinada à prática em ambiente controlado.

## Procedimentos

Foram realizadas as seguintes atividades:

1. Configuração da rede Host-Only.
2. Validação da conectividade entre as máquinas.
3. Identificação dos serviços expostos.
4. Avaliação dos mecanismos de autenticação.
5. Registro das evidências encontradas.
6. Análise das medidas de mitigação.

## Resultados

Foram identificados serviços que dependem de autenticação para controle de acesso.

A análise permitiu compreender a importância de:

- políticas de senha fortes;
- autenticação multifator;
- monitoramento de logs;
- segmentação de rede.

## Conclusão

A realização do laboratório proporcionou uma visão prática dos riscos associados à autenticação inadequada e demonstrou a importância da aplicação de controles defensivos para proteção dos serviços.

Todo o estudo foi conduzido em ambiente isolado e controlado para fins exclusivamente educacionais.
