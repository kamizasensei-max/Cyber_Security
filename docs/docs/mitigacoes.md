# Recomendações de Mitigação

## Senhas Fortes

Requisitos recomendados:

- mínimo de 12 caracteres
- letras maiúsculas
- letras minúsculas
- números
- caracteres especiais

---

## MFA

Implementação de autenticação multifator para reduzir riscos relacionados ao uso indevido de credenciais.

---

## Bloqueio de Conta

Configurar:

- bloqueio temporário após múltiplas falhas
- limitação de tentativas consecutivas

---

## Monitoramento

Registrar:

- falhas de login
- acessos administrativos
- alterações de configuração

---

## Segmentação de Rede

Separar:

- rede de usuários
- servidores críticos
- ambientes de laboratório

---

## Atualizações

Manter:

- sistema operacional atualizado
- serviços corrigidos
- aplicações web atualizadas
